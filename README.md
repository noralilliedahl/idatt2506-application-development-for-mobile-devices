# IDATT2506 – Coursework

Assignments (øvinger) for IDATT2506, written in Kotlin with Jetpack Compose.

Each folder is a standalone Android Studio project. To run one, open that folder
(e.g. `oving3/`) in Android Studio, not the repository root.

| Assignment | Topic |
|------------|-------|
| [oving1](oving1) | Activity lifecycle – logs `onCreate`, `onStart`, `onResume`, `onPause`, `onStop` and `onDestroy` |
| [oving2](oving2) | Recipe list – header, `LazyColumn` of recipes, toasts on click and a count button |
| [oving3](oving3) | Friend list – add friends with name and birthday using state and text fields |
| [oving4](oving4) | Friend list app with Navigation Compose, a `ViewModel`, and list/detail/form screens for adding and editing friends |
